# Demo assets

Screenshots of the AgriQNet web app (`http://localhost:3000`), captured on 4 Nov 2026, numbered in story order for a demo video.

- `*-phone.jpg` — 390×690 CSS phone viewport (488×863 px).
- `*-desktop.png` — 1280×720 CSS desktop viewport (1600×900 px, 16:9).
- `manifest.json` — one entry per scene: file, title, caption, device and size, in playback order.

Story: language → login → home → weather → crop & fertilizer (quantum-hybrid) → pest photo → warning → alerts & Alert Network → officer view → Farmer Library → Ask.
